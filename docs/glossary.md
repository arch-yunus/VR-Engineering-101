# Sozluk

| Terim | Kisa aciklama |
| --- | --- |
| HMD | Head-Mounted Display; bas uzerinde tasinan VR/AR goruntu cihazi. |
| IMU | Inertial Measurement Unit; ivmeolcer ve jiroskop temelli hareket sensoru. |
| Motion-to-photon | Fiziksel hareketten ekrandaki piksel degisimine kadar gecen sure. |
| Foveated rendering | Gozun baktigi bolgeyi yuksek, cevreyi dusuk kalitede render etme teknigi. |
| Pose | Konum ve yonelim bilgisinin birlikte ifade edilmesi. |
| Jitter | Paketlerin veya frame surelerinin duzensiz araliklarla gelmesi. |
| Drift | Sensor tahmininin zamanla gercek degerden uzaklasmasi. |
| Spoofing | Sahte veya manipule edilmis veriyle sistemi kandirma girisimi. |
