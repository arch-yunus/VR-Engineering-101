# Modul 4: Ag ve Guvenlik

## Hedef

Cok kullanicili VR sistemlerinde hiz, tutarlilik ve guvenligi birlikte dusunmek.

## Ana Kavramlar

- UDP snapshot ve delta state replication.
- Client prediction, interpolation, jitter buffer.
- Replay korumasi, monoton sequence number, paket imzalama.
- Mahremiyet: pozisyon, bakis yonu, el hareketi ve biyometrik sinyaller.

```bash
python 04_ag_guvenlik/labs/udp_snapshot_packet.py
```
